# El Rincón de las Recetas

Este es un sitio web sencillo hecho con HTML y CSS.

## Cómo abrirlo

Abre el archivo `index.html` en un navegador para ver la página principal.

## Archivos principales

- `index.html`: página principal con recetas, consejos y contacto.
- `recetas.html`: recetas explicadas paso a paso.
- `recetas.css`: colores, tamaños, márgenes y otros estilos.
- `aviso-legal.html`, `privacidad.html` y `cookies.html`: información del sitio.
- `imagenes/`: fotografías que aparecen en las páginas.

## Cómo cambiar el aspecto

Abre `recetas.css` y cambia valores como `color`, `background-color`, `margin` o `padding`. Guarda el archivo y vuelve a cargar la página en el navegador.

El formulario de contacto es solo una demostración. Para enviar mensajes de verdad hace falta conectar la página a un servidor.
